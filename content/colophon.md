# Colophon

*The stack behind this website aims to excel in stability, ease of content editing and publishing, while future-proofing the whole setup.*

I create and edit markdown entries in <a href="https://obsidian.md" target="_blank" rel="noopener noreferrer">Obsidian</a>. Files get pushed to a <a href="https://github.com/psantalla/pablo-website-v2" target="_blank" rel="noopener noreferrer">public GitHub repository</a>, where GitHub Actions runs <a href="https://www.11ty.dev/" target="_blank" rel="noopener noreferrer">Eleventy</a> to turn the markdown into HTML and build the static site.

This website is then hosted on <a href="https://pages.github.com" target="_blank" rel="noopener noreferrer">GitHub Pages</a>.
