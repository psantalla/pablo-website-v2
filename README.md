## Notes

- `build`, not `build-ghpages` (custom domain, no path prefix). Add `--pathprefix=/<repo>/` scripts back if forking onto `*.github.io/<repo>`.
- Video posters (`.webp` from first frame of `.mp4`) generated by `scripts/video-posters.js` on `prestart`/`prebuild`. Gitignored. Needs `ffmpeg` (CI: apt; local: `brew install ffmpeg`).
- Pages deploy via official actions (Pages source = GitHub Actions, env `github-pages` → `main`). `upload-pages-artifact` v4+ excludes dotfiles.

## Additions

- **Projects**: `/projects/` + `/project-topics/`, mirrors posts/tags.
- **Post updates**: `updated` + `changelog` frontmatter; renders timestamp and JSON-LD `dateModified`.
- **Images**: `@11ty/eleventy-img` for all. SVG vector; raster → AVIF/WebP; GIF → animated WebP; responsive `<picture>` + lazy.
- **Video control**: `_includes/components/video-control.njk` macro + `public/js/video-control.js`. Autoplays muted loops in-viewport with a pause/play override; respects `prefers-reduced-motion`.
- **Redirects**: `content/redirects.njk` generates an HTML redirect for any page with a `redirect_from` value in its frontmatter.
